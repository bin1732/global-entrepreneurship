# Global Entrepreneurship
## 全球一人公司创业全链路指导系统

**Complete one-person company entrepreneurship guidance system — covering all countries worldwide, 15-layer closed-loop from user profile to long-term blueprint. Auto-detects language for global adaptability.**
**全球一人公司创业全链路指导系统——覆盖全球所有国家/地区，15层闭环从用户画像到长期蓝图。自动检测输入语言，全球适配。**

---

## ✨ Features | 特性

- 🌍 **Global Coverage** — All countries across 6 economic regions: Asia, Europe, North America, Latin America, Africa, Oceania
  全球覆盖：六大经济区所有国家——亚洲/欧洲/北美/拉美/非洲/大洋洲
- 🔄 **15-Layer Closed-Loop** — From user profiling → market scanning → validation → compliance → launch → growth → global expansion
  15层闭环：用户画像→市场扫描→需求验证→合规→启动→增长→全球拓展
- 🗣️ **Auto Language Detection** — Works in any language, defaults to English when undetectable
  自动语言检测：任何语言均可使用，检测失败默认英文
- 🎯 **Smart Direction Recommendation** — Top 5 business directions with SWOT analysis based on your profile
  智能方向推荐：基于画像的TOP5方向+SWOT分析
- 📋 **Compliance Check** — Target country regulations, tax, data privacy, IP requirements
  全维度合规：目标国法规、税务、数据隐私、知识产权
- 💰 **Revenue Modeling** — 3-tier income forecast + break-even analysis
  变现模型：三档收入预测+盈亏平衡分析
- 📈 **Growth Engine** — Retention, referrals, automation design
  增长引擎：复购/转介绍/自动化设计
- ⚡ **24h MVP Sprint** — From idea to minimum viable product in 24 hours
  24小时MVP冲刺：从想法到可用产品的极速模式
- 📊 **Startup Health Score** — 8-dimensional comprehensive scoring (0-100)
  创业健康评分：8维度综合评分（0-100分）
- 🏛️ **China OPC Policies** — 13 provinces/municipalities one-person company support policies
  中国OPC政策：13个省市一人公司专项扶持政策索引

## 🚀 Quick Start | 快速开始

### Installation in Coze / OpenClaw | 在扣子/OpenClaw中安装

```bash
# Via CLI
skillhub install global-entrepreneurship

# Or download the ZIP and extract to your skills directory
```

### Usage | 使用

Start from anywhere — no forced workflow:

从任何位置开始，不强制全流程：

- "帮我从零开始规划创业" / "plan my business from scratch" — Full 15-layer planning
- "帮我分析日本创业市场" / "analyze startup in Japan" — Country-specific market analysis
- "我想做跨境电商" / "I want to start SaaS" — Industry-specific guidance
- "帮我做个财务模型" / "financial model" — Single-service deep dive
- "今天做什么" / "daily plan" — Daily operations guidance
