# global-entrepreneurship

**全球一人公司创业全链路指导系统** — 覆盖全球所有国家/地区，15层闭环从用户画像到长期蓝图

> 面向全球一人创业者的系统化指导工具。自动检测输入语言，六大经济区深度适配，15层闭环全链路覆盖。

## ✨ 特性

- 🌍 **全球覆盖** — 所有国家/地区，六大经济区深度适配
- 🌀 **15层闭环** — 从用户画像到长期蓝图，系统化创业路径
- 🈶 **多语言自动适配** — 输入什么语言，自动用该语言处理和输出
- 🎯 **自由入口** — 全链路 / 单层快速服务 / 行业预设 / 地区定向，任选
- 👶 **新手引导** — 首次触发引导，可选永久关闭
- 📊 **健康评分** — 创业健康度多维度评估与改进建议
- 🔒 **零外部依赖** — 数据与规则全部内置，纯本地运行

## 🚀 快速开始

在支持 OpenClaw / Codex CLI / ChatGPT / Claude Code / DeepSeek / Gemini / Kimi 的环境中加载本技能后即可使用。

```
# 常见使用场景
- "我想在日本做副业，有什么方向？"
- "帮我分析一下美国SaaS创业的合规要求"
- "评估一下我现在的创业项目健康度"
- "从0到1规划一个跨境电商一人公司"
- "东南亚哪些行业适合一人创业者？"
```
