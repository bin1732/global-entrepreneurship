## 第1层:用户深度画像

### 输入要求
通过对话收集以下信息:
- 核心技能:专业技能列表(如编程、设计、写作、翻译、摄影等)
- 可迁移技能:沟通、管理、销售、教学等
- 可投入时间:每天/每周可用小时数
- 启动资金:可投入金额范围(0/1千/5千/1万/5万/10万+)
- 人脉资源:相关行业人脉、社群资源
- 风险偏好:保守(只求不亏)/稳健(可接受小亏)/激进(可承受较大损失)
- 学习能力:对新技能的掌握速度(快/中/慢)
- 执行风格:计划型(喜欢规划)/行动型(喜欢先干再说)

### 六维评分标准(0-100)
| 维度 | 评分依据 |
|------|----------|
| 技能力 | 专业技能数量、深度、市场稀缺度 |
| 资源力 | 资金+时间+人脉的综合评估 |
| 执行力 | 过往项目完成度、自律程度 |
| 学习力 | 新技能掌握速度、知识更新频率 |
| 风险承受力 | 资金储备、心理承受力、家庭负担 |
| 创新力 | 跨界思维、问题解决能力、创意产出 |

### 输出模板
```
【用户画像报告】
核心标签: [3-5个关键词标签]
技能矩阵: [技能1(熟练度)] [技能2(熟练度)] ...
资源概况: 时间[Xh/天] | 资金[X元] | 人脉[描述]
性格画像: [风险偏好] + [执行风格] + [学习偏好]

六维评分:
  技能力:    [XX]/100  ████████░░
  资源力:    [XX]/100  ██████░░░░
  执行力:    [XX]/100  █████████░
  学习力:    [XX]/100  ███████░░░
  风险承受:  [XX]/100  █████░░░░░
  创新力:    [XX]/100  ████████░░

综合评级: [S/A/B/C]级创业者
适配方向: [方向类型1]、[方向类型2]、[方向类型3]
```

## 第2层:实时市场扫描

### 操作步骤
1. 使用 web_search 搜索以下关键词获取实时数据:
   - "[行业] 市场规模 2024"
   - "[行业] 趋势 增长"
   - "[行业] 竞品 排名"
   - "[行业] 政策 法规"
2. 读取 references/industry-knowledge.md 获取行业基础数据
3. 综合分析形成市场机会评分

### 市场机会评分维度(每项1-10分)
| 维度 | 评估标准 |
|------|----------|
| 需求热度 | 搜索量、讨论度、用户痛点强度 |
| 竞争程度 | 竞品数量、头部集中度、差异化空间(分数越高竞争越小) |
| 进入壁垒 | 资金门槛、技术门槛、资质要求(分数越高壁垒越低) |
| 增长潜力 | 市场增速、新兴需求、技术驱动 |
| 政策友好度 | 政策支持力度、监管风险、合规难度 |

### 输出模板
```
【市场机会评分表】
方向1: [名称]
  需求热度: [X]/10 | 竞争程度: [X]/10 | 进入壁垒: [X]/10
  增长潜力: [X]/10 | 政策友好: [X]/10 | 综合评分: [X]/50
  关键发现: [1-2句核心洞察]
  数据来源: [标注搜索来源]
```

## 第4层:需求验证设计

### 48小时MVP验证方案
- 明确MVP定义:最小可行产品的核心功能/服务是什么
- 48小时时间分配:
  - 0-8h: 搭建最小产品/服务原型
  - 8-24h: 制作落地页/展示页
  - 24-36h: 在目标渠道发布并收集反馈
  - 36-48h: 分析数据，判断是否继续

### 零成本测试方法(至少5种)
1. 落地页测试: 制作产品介绍页，投放到目标社群，统计点击和留资
2. 社群投票: 在目标用户社群发起需求投票
3. 竞品评论区分析: 分析竞品差评，发现未被满足的需求
4. 论坛需求挖掘: 在知乎/Reddit/论坛搜索相关需求帖
5. 预售测试: 在产品完成前开启预售，验证付费意愿
6. 免费试用招募: 招募beta用户免费试用，收集反馈

### 成功/失败判断标准
- 成功: 48h内获得[X]个有效留资 / [X]个付费预售 / [X]条正面反馈
- 失败: 48h内留资<[X] / 零付费意愿 / 反馈均为负面
- 需调整: 有 interest 但具体功能/价格需调整

## 第5层:全维度合规检查

### 检查维度与风险等级
| 维度 | 检查内容 | 红色风险 | 黄色风险 | 绿色安全 |
|------|----------|----------|----------|----------|
| 广告法 | 宣传用语合规 | 使用绝对化用语 | 夸大效果 | 客观描述 |
| 电商法 | 经营资质 | 无照经营 | 资质过期 | 证照齐全 |
| 税务 | 纳税申报 | 偷税漏税 | 延迟申报 | 按时申报 |
| 数据隐私 | 用户数据保护 | 无隐私协议 | 协议不完善 | GDPR合规 |

| 平台规则 | 平台政策 | 明确违规 | 灰色地带 | 完全合规 |
| 行业资质 | 特殊行业许可 | 无资质经营 | 资质待更新 | 资质齐全 |

## 第8层:产品体系设计

### 产品矩阵设计
| 层级 | 定位 | 价格区间 | 目的 | 示例 |
|------|------|----------|------|------|
| 引流款 | 免费/超低价 | 0-9.9元 | 获取信任、筛选客户 | 免费模板、试用装 |
| 利润款 | 核心产品 | 99-999元 | 主要收入来源 | 课程、工具、服务 |
| 高端款 | 增值服务 | 999-9999元 | 提升客单价 | 1v1咨询、定制服务 |

### 定价策略三选一
1. 成本加成法: 成本 x (1 + 目标利润率) = 价格
2. 竞品跟随法: 参考竞品价格，略低/持平/略高
3. 价值定价法: 基于客户获得的价值定价(推荐)

## 第13层:创新创意方案

### 五种创新方法
1. 交叉创新: 将A行业的成功模式移植到B行业(如:将SaaS订阅模式用于实体产品)
2. 颠覆创新: 去除价值链中某个高成本环节(如:去除中间商直接DTC)
3. 微创新: 在现有产品上增加一个新功能或新场景(如:增加AI辅助功能)
4. 组合创新: 将多个元素重新组合(如:课程+社群+工具=学习系统)
5. 场景创新: 发现产品的新使用场景(如:从B端转向C端)

### 输出要求
- 至少生成10个创新方案
- 每个方案标注:创新类型、可行性(1-5)、预期收益(1-5)、实施难度(1-5)
- 按"可行性x预期收益/实施难度"排序，给出优先级

### 组织进化节点

|------|----------|----------|
