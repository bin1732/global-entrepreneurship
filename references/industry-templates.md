# 行业模板（6大行业预设）

---

## 1. 自媒体模板

| 预设项 | 内容 |
|--------|------|
| **适用对象** | 内容创作者、博主、播客主 |
| **预设方向** | 公众号运营、短视频创作、知识付费、广告合作 |
| **专属功能** | 内容日历、平台数据分析、选题库、粉丝互动 |
| **关键指标** | 粉丝数、阅读量、转化率、客单价、复购率 |
| **推荐工具** | 小红书/公众号/抖音后台、Notion、Canva |

## 2. 电商模板

| 预设项 | 内容 |
|--------|------|
| **适用对象** | 网店经营者、独立站卖家 |
| **预设方向** | 淘宝/拼多多运营、独立站、直播带货 |
| **专属功能** | 商品管理、订单追踪、供应商管理、营销日历 |
| **关键指标** | GMV、客单价、复购率、退货率、获客成本 |
| **推荐工具** | Shopify、店小秘、ERP系统 |

## 3. 咨询模板

| 预设项 | 内容 |
|--------|------|
| **适用对象** | 独立顾问、教练、策划人 |
| **预设方向** | 管理咨询、职业规划、营销策划 |
| **专属功能** | 客户案例管理、知识库、项目追踪 |
| **关键指标** | 项目数、客单价、客户满意度、转介绍率 |
| **推荐工具** | Notion、飞书、Calendly |

## 4. 教育模板

| 预设项 | 内容 |
|--------|------|
| **适用对象** | 在线教育者、课程创作者 |
| **预设方向** | 录播课、直播课、训练营、1v1辅导 |
| **专属功能** | 学员管理、课程进度、评估体系 |
| **关键指标** | 学员数、完课率、好评率、转介绍率 |
| **推荐工具** | 小鹅通、知乎、ClassIn |

## 5. 直播模板

| 预设项 | 内容 |
|--------|------|
| **适用对象** | 主播、直播运营者 |
| **预设方向** | 娱乐直播、带货直播、知识直播 |
| **专属功能** | 直播排期、视频制作、互动管理、打赏/带货分析 |
| **关键指标** | 观看人数、互动率、转化率、收入 |
| **推荐工具** | 抖音/快手、OBS、直播伴侣 |

## 6. 跨境模板

| 预设项 | 内容 |
|--------|------|
| **适用对象** | 跨境卖家、出海创业者 |
| **预设方向** | 亚马逊、独立站跨境、TikTok跨境 |
| **专属功能** | 多语言支持、多币种管理、国际物流、各国合规检查 |
| **关键指标** | 各国GMV、汇率影响、物流时效、退货率 |
| **推荐工具** | Shopify、亚马逊全球开店、Easyship、Payoneer |
