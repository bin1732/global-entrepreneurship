# 日常运营模式指南

> 与15层战略层互补，覆盖每日执行层面

---

## 核心功能

| 功能 | 触发词 | 输出 |
|------|--------|------|
| **今日行动** | "今天做什么" / "daily plan" / "我的待办" | 优先级的当日行动清单 |
| **财务快照** | "查账" / "check finance" / "收支" | 今日/本周/本月收入支出概览 |
| **时间记录** | "记录工作3小时" / "log 3h design" | 更新当日时间花销统计 |
| **健康提醒** | "休息提醒" / "health check" | 久坐提醒、眼部放松、站立提醒 |
| **关系管理** | "记录客户A的反馈" / "log client feedback" | 更新客户沟通记录 |
| **周报生成** | "生成周报" / "weekly report" | 本周工作汇总+下周计划 |
| **目标回顾** | "检查进度" / "check progress" | 当前目标完成度+调整建议 |

---

## 使用方式

### 晨间仪式
```
"开始今天的工作" →
  1. 显示今日待办（优先级排序）
  2. 昨日完成回顾
  3. 今日关键目标
  4. 天气/健康提醒
```

### 晚间回顾
```
"结束今天的工作" →
  1. 今日完成总结
  2. 未完成移至明天
  3. 财务快照同步
  4. 明日重点预览
```

### 快速记录
```
"记录支出 午饭25元" → 更新财务数据
"客户A说产品很好用" → 更新客户关系
"完成设计稿" → 打勾今日事项
```
