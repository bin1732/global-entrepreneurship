# 创业健康评分系统

> 8轴0-100分综合评估，对标1Founder的8-axis scoring system

---

## 一、8轴评分体系

### 轴1：问题清晰度（Problem Clarity）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 问题极其清晰 | 能用一句话说清谁在什么场景下遇到什么痛点；有用户访谈验证；痛点频率高、紧迫性强 |
| 70-89 | 问题较清晰 | 能描述目标用户和痛点，但缺乏访谈验证；痛点存在但紧迫性一般 |
| 50-69 | 问题模糊 | 知道大致方向但说不清具体痛点；或者痛点是"假设"而非"验证"的 |
| <50 | 问题未定义 | 只有一个"想法"但没有明确的问题定义；自嗨型创业 |

### 轴2：市场时机匹配（Market Timing）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 时机完美 | 技术成熟+需求爆发+政策利好同时具备；窗口期明确在6-24个月内 |
| 70-89 | 时机良好 | 需求在增长，技术基本成熟，政策中性偏正面 |
| 50-69 | 时机一般 | 市场存在但增长缓慢；或技术/政策仍有不确定性 |
| <50 | 时机不佳 | 市场萎缩/技术不成熟/政策限制；或窗口期已过 |

### 轴3：创始人与市场匹配（Founder-Market Fit）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 极度匹配 | 创始人在该领域有3年+深度经验；有行业人脉；亲身经历过痛点 |
| 70-89 | 较好匹配 | 有相关经验（1-3年）；对行业有基本认知；有部分人脉 |
| 50-69 | 一般匹配 | 通过研究了解了行业；没有直接经验但有关联技能 |
| <50 | 不匹配 | 完全不熟悉该行业；仅凭"看起来不错"进入 |

### 轴4：推向市场准备度（Go-to-Market Readiness）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 高度准备 | 已有种子用户/等候名单；获客渠道明确且已测试；内容资产已积累 |
| 70-89 | 较好准备 | 获客渠道已规划；有初始内容或社区基础；未开始但路径清晰 |
| 50-69 | 准备不足 | 知道需要获客但未规划具体渠道；没有内容资产或社区基础 |
| <50 | 未准备 | "做好产品自然有人来"心态；没有任何获客准备 |

### 轴5：收入模式可行性（Revenue Model Viability）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 高度可行 | 已有付费用户或强有力的付费意愿验证；LTV/CAC模型清晰且健康 |
| 70-89 | 较可行 | 定价有市场对标；目标用户付费能力已确认；模型合理但未验证 |
| 50-69 | 可行性存疑 | 有定价想法但缺乏验证；或目标用户付费意愿不明 |
| <50 | 不可行 | "先免费做大再变现"思维；没有明确的变现路径 |

### 轴6：资金充足度（Capital Adequacy）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 高度充足 | 有12个月+的个人生活费储备；启动资金已到位；有持续收入或副业支撑 |
| 70-89 | 较充足 | 有6-12个月储备；启动资金基本到位 |
| 50-69 | 偏紧张 | 有3-6个月储备；资金来源不稳定 |
| <50 | 不足 | 少于3个月储备；需要立刻盈利否则无法持续 |

### 轴7：可扩展性（Scalability）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 高度可扩展 | 数字产品/自动化服务；边际成本趋近于零；收入与时间解耦 |
| 70-89 | 较可扩展 | 产品化程度高；有部分自动化；收入部分与时间解耦 |
| 50-69 | 扩展性一般 | 半产品化半服务；收入与时间部分关联；需要工具/流程优化 |
| <50 | 难以扩展 | 纯时间换钱模式；收入完全与工时挂钩；无产品化路径 |

### 轴8：执行风险（Execution Risk）

| 分数段 | 描述 | 典型特征 |
|--------|------|----------|
| 90-100 | 风险极低 | 有成功执行类似项目的记录；团队/工具/流程已就绪；关键路径清晰 |
| 70-89 | 风险较低 | 有相关执行经验；大部分资源已到位；有明确的里程碑计划 |
| 50-69 | 风险中等 | 缺乏部分关键技能或资源；执行路径存在不确定性 |
| <50 | 风险高 | 缺乏核心执行能力；没有可参考的执行经验；依赖外部不可控因素 |

## 二、综合评分计算

### 公式
```
综合分 = Σ(轴i × 权重i) / Σ权重i

权重分配：
  问题清晰度：20%
  市场时机匹配：15%
  创始人与市场匹配：15%
  推向市场准备度：10%
  收入模式可行性：15%
  资金充足度：10%
  可扩展性：10%
  执行风险：5%
```

### 风险等级映射

| 综合分 | 等级 | 颜色 | 行动建议 |
|--------|------|------|----------|
| 80-100 | A级 | 🟢 | 全速推进，关注薄弱轴 |
| 65-79 | B级 | 🟡 | 优先补强弱项轴再全速推进 |
| 50-64 | C级 | 🟠 | 重大问题需解决，建议Pivot或深度调整 |
| <50 | D级 | 🔴 | 严重问题，建议重新评估方向 |

## 三、各轴低于70分的行动项

### 问题清晰度 < 70
1. 进行10+目标用户深度访谈
2. 用"5个为什么"深挖痛点根因
3. 写出"谁在什么场景下遇到什么问题"的一句话描述
4. 验证痛点频率（每周/每月发生几次）

### 市场时机匹配 < 70
1. 研究目标市场的技术成熟度曲线
2. 查找目标市场的政策/法规变化趋势
3. 分析竞品融资动态（融资加速=窗口期打开）
4. 评估是否有6-24个月的时间窗口

### 创始人与市场匹配 < 70
1. 在目标行业做3个月深度沉浸（工作/咨询/社区）
2. 建立至少5个行业核心人脉
3. 找到亲身经历该痛点的故事
4. 考虑找一个该领域的联合创始人/顾问

### 推向市场准备度 < 70
1. 选择1-2个主要获客渠道并开始测试
2. 开始积累内容资产（至少10篇/条）
3. 建立种子用户群（目标50人）
4. 设计MVP的等候名单机制

### 收入模式可行性 < 70
1. 找到3个同类产品的定价参照
2. 对5+目标用户进行付费意愿访谈
3. 计算LTV/CAC模型（目标>3:1）
4. 设计最小化付费验证实验

### 资金充足度 < 70
1. 确保至少6个月生活费储备
2. 保留一份副业/兼职收入来源
3. 列出启动所需的最低成本清单
4. 探索OPC扶持政策（中国用户）

### 可扩展性 < 70
1. 识别时间换钱的部分并设计产品化方案
2. 引入自动化工具（AI Agent/脚本/模板）
3. 设计标准化交付流程
4. 评估哪些环节可以被AI替代

### 执行风险 < 70
1. 列出关键执行步骤并标注技能缺口
2. 为每个缺口找到AI工具或外包方案
3. 制定30天里程碑计划
4. 找到1-2个有执行经验的导师/顾问

## 四、与1Founder 8轴系统对比

| 轴 | 本系统 | 1Founder | 差异说明 |
|----|--------|----------|----------|
| 问题清晰度 | ✅ | ✅ | 相同维度，本系统增加评分细则 |
| 市场时机 | ✅ | ✅ | 本系统增加窗口期量化 |
| 创始人匹配 | ✅ | ✅ | 相同维度 |
| GTM准备度 | ✅ | ✅ | 本系统增加渠道测试要求 |
| 收入模式 | ✅ | ✅ | 本系统增加LTV/CAC验证 |
| 资金充足度 | ✅ | ✅ | 本系统增加OPC政策适配 |
| 可扩展性 | ✅ | ✅ | 本系统增加AI自动化评估 |
| 执行风险 | ✅ | ✅ | 本系统增加AI工具补充方案 |

## 五、使用方式

在全链路第3层（智能方向推荐）后自动触发创业健康评分：
1. 对每个推荐方向分别打8轴评分
2. 输出综合分与风险等级
3. 识别低于70分的轴并给出行动项
4. 推荐综合分最高的方向

用户也可随时触发：说"创业健康评分"/"health check"/"评分"。
